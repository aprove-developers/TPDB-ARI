# New Relative TRS Benchmarks (Kassing)

The five secret benchmarks for AProVE contain terminating relative TRSs
that model algorithms on data structures
where the base B is not dominated by the main R.
Therefore, we cannot use the technique from Iborra et. al. (JAR'2017) to use ordinary dependency pairs.
The ADP framework implemented in AProVE however is able to prove relative termination.
